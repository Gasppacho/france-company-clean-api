# Changelog

All notable user-facing changes are recorded here.

## [0.1.0] - 2026-07-24

### Added

- normalized French company search endpoint;
- stable JSON response models and bounded pagination;
- one-hour in-memory cache with cache-status headers;
- safe validation and upstream error responses;
- optional RapidAPI proxy-secret enforcement;
- health endpoint and OpenAPI documentation;
- Python, JavaScript, and CSV-enrichment examples;
- reproducible container deployment.
