# Security policy

Do not report passwords, API keys, cookies, personal data, or vulnerability details in a public issue.

Report security concerns privately to **q.services.entreprise@gmail.com** with the subject `SECURITY — France Company Clean API`. Include the affected endpoint, reproduction steps, and impact. Q Services will acknowledge valid reports as soon as operationally possible; no fixed remediation deadline is promised.

The API intentionally returns only a minimized subset of the official company-search payload. It does not return directors or financial records.
